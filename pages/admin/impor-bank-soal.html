Validasi format JSON ketat sebelum tulis. Root harus array soal. Field wajib + aturan per jenisSoal. Payload dibersihkan (field asing dibuang, string di-trim).

1. JSON 2. Validasi 3. Impor

1. Siapkan JSON

UTF-8 · array [ {...}, {...} ] · bukan objek pembungkus. Maks. disarankan 2000 soal/file.

Atau tempel di bawah.

Kode TP valid (klik = salin)

2. Validasi format & isi

Cek struktur JSON, tipe field, mapel/TP/KKO/kompleksitas, dan kelengkapan per jenis soal. Satu error = tidak impor.

3. Impor

Hanya payload yang sudah dinormalisasi (bersih) yang ditulis. Batch 400.
