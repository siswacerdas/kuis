Setup latihan (sekali pakai)

Hanya untuk guru. Membuat sheet Bank_Soal, Daftar_Latihan, dan Hasil_Latihan.

1. Buat sheet latihan

Harus sama dengan GURU_TOKEN di Code.gs.

2. Impor bank soal (CSV di Spreadsheet)

  1. Buka spreadsheet Database_Kuis.
  2. Buka sheet Bank_Soal.
  3. Menu File → Import → Upload → file CSV bank soal.
  4. Pilih Append (jangan dobel header).

3. Isi sesi latihan

  1. Buka sheet Daftar_Latihan.
  2. Salin baris dari CSV contoh (token contoh LATIHAN1).

4. Selesai

  1. Code.gs harus sudah Deploy (New version) sebelum tombol di atas.
  2. Siswa membuka halaman latihan.
