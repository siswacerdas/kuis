Setup latihan (sekali pakai)

Halaman ini untuk guru. Membuat sheet Bank_Soal, Daftar_Latihan, dan Hasil_Latihan lewat tombol — tanpa membuka dropdown Run di Apps Script.

1. Buat sheet latihan

Harus sama dengan SETUP_TOKEN di Code.gs. Ganti di Code.gs setelah setup selesai bila perlu.

2. Impor bank soal (CSV)

  1. Buka spreadsheet Database_Kuis.
  2. Buka sheet Bank_Soal (sudah dibuat di langkah 1).
  3. Menu File → Import → Upload → pilih file 4-Spreadsheet-Bank_Soal.csv.
  4. Pilih Append atau ganti data (jangan dobel header).

Impor 126 soal lewat CSV di Sheets lebih stabil daripada lewat web (batas waktu Apps Script).

3. Isi sesi latihan

  1. Buka sheet Daftar_Latihan.
  2. Salin baris dari file 5-Spreadsheet-Daftar_Latihan.csv (token contoh LATIHAN1).
  3. Pastikan kolom ID_Soal_List memakai ID yang ada di Bank_Soal, dipisah titik koma.

4. Selesai

  1. Pastikan Code.gs sudah di-Deploy (New version) sebelum menekan tombol di atas.
  2. Buka halaman siswa: latihan/index.html
  3. Setelah setup berhasil, halaman ini boleh dihapus dari repo atau tidak dibagikan ke siswa.
